## Что сделать в `apps/web/src/domain/visibility.ts`
1. Типы:
   - `VisibilityViewer = { readonly id: string } | null` (оставить).
   - `ViewerRelations` — факты отношения зрителя к владельцу списка, которые приходят снаружи: `{ blocked: boolean; friend: boolean; subscriber: boolean; contactMatch: boolean; viaListToken: boolean }`. Константа `NO_RELATIONS` (всё false). JSDoc: откуда каждый факт придёт (Block/Friendship — Epic 4 AD-10, Subscription — AD-19, ContactMatch — AD-18 Epic 8, viaListToken — зритель пришёл по `/l/:publicToken`, Story 3.3).
   - `VisibilityGift = { ownerId; visibility; archivedAt: Date | null }`.
   - `ViewerRole = "owner" | "viewer"`.
2. `VisibilityPolicy.canSee(viewer, relations, gift): boolean`:
   - владелец (`viewer?.id === gift.ownerId`) → true всегда (SECRET и архив тоже);
   - не владелец: `relations.blocked` → false; `archivedAt !== null` → false; SECRET → false; FRIENDS → `friend`; PUBLIC → `friend || subscriber || contactMatch || viaListToken`;
   - аноним (null) может видеть только PUBLIC и только при `viaListToken`; любые friend/subscriber/contactMatch у анонима игнорируются.
3. `VisibilityPolicy.resolve(viewer, relations, list, gifts)` где `list: { ownerId: string } | null`, `gifts: readonly T[]` (`T extends VisibilityGift`):
   - `list === null` → `{ access: "not_found", gifts: [], role: null }`;
   - не владелец и `relations.blocked` → `not_found` (AD-7 шаг 2);
   - иначе `{ access: "gifts", gifts: gifts.filter(canSee), role }`. Порядок сохраняется. Никаких счётчиков/флагов «есть скрытые».
   - `gift.ownerId` должен совпадать с `list.ownerId`: желание с чужим ownerId выкидывается (защита от ошибки вызывающего).
4. `VisibilityPolicy.allowedVisibilities(viewer, relations, ownerId): GiftVisibility[]` — какие значения visibility этот зритель может видеть (для where-фильтра в БД, чтобы скрытые даже не читались): владелец → все три; иначе по правилам выше (blocked → []).
5. Старую сигнатуру `resolve(viewer, gift)` убери и поправь единственного вызывающего `apps/web/src/actions/my-gifts.ts` минимально: `canSee({id: ownerId}, NO_RELATIONS, {ownerId: list.ownerId, visibility: row.visibility, archivedAt: row.archivedAt})`. Больше ничего в my-gifts не меняй (его переделка — микрозадача 04).
