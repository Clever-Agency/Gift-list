## Что сделать
Новый `apps/web/src/domain/viewer-gift-card.ts`:
- `ViewerGiftRow` — как `OwnerGiftRow` + `reservationBought: boolean`, `holderVisibleToOthers: boolean`.
- `toViewerGiftCard(row, viewerId: string | null): GiftCard`:
  - поля желания как у владельца (title…archivedAt, tags: []), `expiresOn` — календарная дата ISO как в owner-gift-card (вынеси `calendarDay` в общий маленький модуль `apps/web/src/domain/calendar-day.ts` и используй в обоих — это единственная допустимая правка owner-gift-card.ts);
  - `ownerAction`: всегда null (только владельцу);
  - держатель (`viewerId !== null && row.reservedBy?.id === viewerId && status === "RESERVED"`): `reservedBy` = он сам;
  - остальные: `reservedBy` только если `holderVisibleToOthers`, иначе null (даже при RESERVED);
  - `reservationLabel` (и держателю, и другим) только при `status === "RESERVED"`: `GIVEN` если `reservationPhase === "GIVEN"`, иначе `BOUGHT` если `reservationBought`, иначе null. Для OPEN/CLOSED — null, `reservedBy` для OPEN — null.
  - фазы ACTIVE/AWAITING_* и dueAt не раскрываются никак.
- Экспорт из `apps/web/src/domain/index.ts` не обязателен; если добавляешь — проверь, что ничего не ломается.
