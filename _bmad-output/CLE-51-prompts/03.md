# CLE-51 / 03 — mobile: клиент deleteGift

Сервер (микрозадача 02) отдаёт `DELETE /api/v1/me/gifts/{id}` → `{ok:true,data:{id}}`; ошибки — `NOT_FOUND` (404), `CONFLICT` (409, желание не OPEN), `UNAUTHENTICATED`.

## Что сделать — `apps/mobile/src/api/my-gifts.ts`
Добавь, по образцу `updateGift`/`fetchGift`:
```ts
export type DeleteGiftResult =
  | { ok: true }
  | { ok: false; invalid: true }
  | Exclude<ClientResult<unknown>, { ok: true }>;
export async function deleteGift(id: string): Promise<DeleteGiftResult>
```
- `apiRequest<unknown>(\`/api/v1/me/gifts/${encodeURIComponent(id)}\`, { method: "DELETE" })`. Посмотри в `src/api/client.ts`, поддерживает ли `apiRequest` DELETE без body (если нет — минимально добавь, не ломая остальных).
- Успешный ответ проверяй zod-схемой `z.object({ id: z.string() })` — если в `@gift-list/contracts` нет схемы, допустимо объявить локальную через `zod` только если `zod` уже есть в зависимостях apps/mobile; иначе проверь вручную `typeof data === "object" && data !== null && typeof data.id === "string" && data.id === id`. Несовпадение → `{ ok:false, invalid:true }`.
