Добавь необязательный `onPress?: () => void`. Если передан — корень `Pressable` с `accessibilityRole="button"`, `aria-haspopup="dialog"`, `accessibilityLabel={t2("visibilityChipLabel", { value: tLower(visibility) })}`, `hitSlop` так, чтобы зона касания ≥44 (`spacing["touch-target"]`), pressed-opacity как у других Pressable. Без `onPress` — как сейчас (просто View). Убери из JSDoc фразу «Choice and saving are Story 2.3; here it only shows the value».

## 3. `apps/mobile/src/ui/gift-card.tsx`
- Новый проп `onVisibilityPress?: () => void`. Чип нажимается ТОЛЬКО если проп передан И `gift.status === "OPEN"` (RESERVED/CLOSED — чип не нажимается, DESIGN.md).
- Вложенные нажимаемые элементы недопустимы: вынеси `footer` с чипом ИЗ `Pressable` тела карточки — он становится соседом после `Pressable` внутри `role="listitem"` View, с теми же отступами (`paddingHorizontal: card-padding`, `paddingBottom: card-padding`), так, чтобы визуально карточка не изменилась. Без `onVisibilityPress` чип остаётся там же, внизу.
- После закрытия выбора фокус должен вернуться на чип: дай чипу `ref` (через проп `chipRef?: React.Ref<View>` в VisibilityChip) — экран (микрозадача 05) решит, куда фокус; здесь только прокинь ref наружу пропом `visibilityChipRef`.
