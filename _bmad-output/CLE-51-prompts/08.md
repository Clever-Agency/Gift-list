# CLE-51 / 08 — фокус в диалогах: подложка не в порядке Tab, фокус на нужной кнопке при открытии

## Проблема (найдено при живой проверке, web 390/320px)
Файлы: `apps/mobile/src/ui/visibility-picker.tsx` (подложка `Pressable` с `aria-hidden`, ~строки 63–71) и `apps/mobile/src/ui/confirm-dialog.tsx` (такая же подложка, ~строки 55–62).

Воспроизведение (Expo web): на «Мой вишлист» Tab до чипа «Видимость: …. Изменить» → Enter. Или на экране правки открытого желания Enter на «Удалить желание».
Сейчас: `document.activeElement` после открытия — `<div aria-hidden="true" tabindex="0">` (подложка). Цикл Tab внутри диалога: Всем → Друзьям → Секрет → Отмена → DIV(подложка) → Всем. Фокусируемый элемент внутри `aria-hidden` — нарушение доступности (WCAG 4.1.2), скринридер попадает «в пустоту».

## Ожидаемое поведение
1. Подложка (scrim) не фокусируется ни мышью, ни клавиатурой: на web у её DOM-узла нет `tabindex="0"` (должен быть `-1` или отсутствовать), на native `focusable={false}`. Тап/клик по подложке по-прежнему закрывает диалог (`onClose` / `onCancel`).
2. При открытии (`visible` стал `true`) фокус переходит внутрь диалога:
   - `VisibilityPicker` — на выбранный сейчас вариант (radio со значением `value`);
   - `ConfirmDialog` — на кнопку отмены (`cancelLabel`, «Отмена»): для разрушительного действия безопасный вариант по умолчанию (`EXPERIENCE.md` → подтверждение удаления; WAI-ARIA APG alertdialog).
3. Tab/Shift+Tab циклятся только по интерактивным элементам диалога, подложки в цикле нет.
4. Esc закрывает, как сейчас; возврат фокуса на вызвавший элемент (чип / «Удалить желание») уже работает — не ломай его.

## Как сделать
- У подложки добавь `focusable={false}` и web-атрибут `tabIndex={-1}` (через тот же приём, что и `aria-haspopup` в `visibility-chip.tsx`: `{...{ tabIndex: -1 }}`), оставь `aria-hidden`.
- Для начального фокуса — ref на нужный элемент и `useEffect` по `visible`, вызов `.focus()` после того, как Modal отрисован (на web может понадобиться `requestAnimationFrame`/`setTimeout(…,0)`). Если `ChoiceGroup` не отдаёт ref на вариант — добавь в `ChoiceGroup` необязательный проп для ref/`autoFocusValue`, не меняя поведение остальных мест использования.
- Только именованные функции (`function focusSelected() {…}`), никаких стрелочных компонентов/хуков-переменных; стрелочные коллбэки в JSX допустимы, как в соседнем коде.
