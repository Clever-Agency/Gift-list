# CLE-51 / 10 — тест: сетевая ошибка при смене видимости показывает тост «Нет соединения»

## Контекст
При живой проверке откат чипа при обрыве сети работал, но наличие тоста «Нет соединения. Попробуйте ещё раз.» (`app.form.network`) не было зафиксировано. Код в `apps/mobile/app/(app)/index.tsx`, `changeVisibility` (ветка `"network" in result`, ~строки 350–358) его выставляет, но отдельного теста на эту ветку для смены видимости нет.

## Что сделать
Только тест (код экрана меняй, ТОЛЬКО если тест покажет, что тоста нет).
В `apps/mobile/src/session/my-wishlist-screen.test.tsx`, рядом с тестом «VALIDATION: откат…» (~строка 1190), добавь тест «сеть: откат чипа и тост «Нет соединения»»:
1. список с одним `OPEN` желанием `visibility: "SECRET"`;

3. `apiRequest` для `PATCH /api/v1/me/gifts/{id}` отвечает `{ ok: false, network: true }`;
4. ожидай: чип снова «Видимость: секрет. Изменить» (откат), на экране текст «Нет соединения. Попробуйте ещё раз.», перезагрузки списка (повторного GET `/api/v1/me/gifts`) нет;
5. повторный тап по чипу снова открывает диалог (флаг «сохранение в процессе» сброшен).
Используй существующие хелперы файла (`respond`, `press`, `text`, `mount`) и тот же стиль.
