# Отчёт по микротаске 2.4.2 — CLE-49 / Story 2.4

Ветка: `evivanchikov/cle-49-story-24-kopirovanie-ssilki-na-vishlist` (продолжение 2.4.1).

## Что сделано

Появился один конфигурируемый источник публичного адреса сайта для ссылки `https://{origin}/l/{publicToken}` (Q-2, AD-6). Домена в коде нет.

Изменённые и новые файлы:

- `apps/mobile/src/config/env.ts` — новый публичный геттер `getPublicWebOrigin()`:
  - читает `EXPO_PUBLIC_WEB_ORIGIN`; если он пуст — берёт `EXPO_PUBLIC_API_BASE_URL`, потому что сайт и API живут на одном домене (AD-26), и App Links уже объявляют `/l/*` на этом хосте (`app.config.ts`);
  - `normalizeWebOrigin()` убирает пробелы и хвостовые слэши (`https://gift.example/` → `https://gift.example`), сохраняет схему и порт;
  - принимается только http(s)-ориджин без пути, query и fragment. Явно заданное, но неверное значение не подменяется API-хостом: helper возвращает `""` — лучше пустая ссылка, чем чужой хост;
  - пустая строка означает «не настроено», как у `getApiBaseUrl()`: вызывающий код не должен собирать ссылку.
- `apps/mobile/src/wishlist/share-link.ts` — `wishlistShareLink(publicToken, origin?)` собирает `${origin}/l/${encodeURIComponent(publicToken)}` и возвращает `null`, если ориджин или токен пустые. Это заготовка для кнопки 2.4.3, UI не добавлен.
- `apps/mobile/.env.example` — документирована `EXPO_PUBLIC_WEB_ORIGIN` (пусто → `EXPO_PUBLIC_API_BASE_URL`; только http(s)-ориджин; значение вшивается в бандл при сборке).
- `README.md` — одна строка про публичный адрес ссылок вишлиста рядом с описанием `EXPO_PUBLIC_*`.
- Тесты:
  - `apps/mobile/src/config/env.test.ts` — нормализация (пробелы, один и несколько хвостовых слэшей, порт), отказ для пустого/не-http(s)/пути/query/fragment, приоритет `EXPO_PUBLIC_WEB_ORIGIN`, откат на `EXPO_PUBLIC_API_BASE_URL`, отсутствие откатa при неверном явном значении, пустой результат без обеих переменных.
  - `apps/mobile/src/wishlist/share-link.test.ts` — полный URL, хвостовой слэш, кодирование токена, `null` без ориджина/токена, чтение ориджина из env по умолчанию.

## Переменные окружения

| Переменная | Где | Смысл |
| --- | --- | --- |
| `EXPO_PUBLIC_WEB_ORIGIN` | `apps/mobile/.env`, окружение сборки Expo | Публичный адрес сайта для ссылок наружу (Q-2). Основной источник. |
| `EXPO_PUBLIC_API_BASE_URL` | там же | Запасной источник, если `EXPO_PUBLIC_WEB_ORIGIN` пуст: по AD-26 API и сайт на одном домене. |

Серверную схему `getEnv()` в этом срезе не меняли: для Story 2.4 ссылка собирается на клиенте. Когда появятся серверные ссылки (письма, приглашения `/i/…`), их ориджин логично брать из `BETTER_AUTH_URL` — это уже обязательная переменная с публичным адресом сайта, отдельная сущность не нужна.

Чтобы `https://{домен}/l/{token}` работала и в веб-сборке, `EXPO_PUBLIC_WEB_ORIGIN` (или `EXPO_PUBLIC_API_BASE_URL`) нужно задать в окружении сборки на Vercel/сервере: `EXPO_PUBLIC_*` вшиваются в SPA (`sync-spa`). Секретов здесь нет.

## Как клиент читает ориджин

```ts
import { getPublicWebOrigin } from "@/config/env";
import { wishlistShareLink } from "@/wishlist/share-link";

const link = wishlistShareLink(publicToken); // "https://gift.example/l/abc" | null
```

В 2.4.3 экран «Мой вишлист» возьмёт `publicToken` из `fetchMyGifts()` (2.4.1), вызовет `wishlistShareLink()` и при `null` покажет ошибку вместо копирования битой ссылки.
