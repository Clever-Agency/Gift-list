## Ревью и остаточные вопросы

Blind review нашёл 13 пунктов. Исправлено в этой задаче: добавлен тест на совместную смену `quantity` + `visibility` вне `OPEN` (`field: "visibility"`), дополнен JSDoc контракта, добавлен комментарий про временный `SINGLE` в mobile payload, спека дополнена файлами и проверками. Остальное — предлагаемые fixup-микротаски, не реализованы:

1. **F-2.5.1-1: no-op `quantity` всё равно пишет строку.** `PATCH` только с сохранённым `quantity` удаляет поле из `data`, и `prisma.gift.update({ data: {} })` обновляет `updatedAt`; то же уже есть у `visibility`. Fixup: при пустом `data` возвращать текущую карточку без записи (общий guard для обоих полей).
2. **F-2.5.1-2: нет теста quantity-only no-op.** Same-value покрыт только вместе с реальным изменением другого поля. Добавить после решения по F-2.5.1-1.
3. **F-2.5.1-3: форма не маппит `field: "quantity"`.** `apps/mobile/src/ui/gift-form-validation.ts` и `gift-form-dirty.ts` не знают нового поля; это часть UI-среза 2.5.2.
4. **F-2.5.1-4: дефолт `SINGLE` продублирован на клиенте.** `apps/mobile/app/(app)/gifts/new.tsx` шлёт константу, потому что `createGift` принимает output-тип `GiftInput`. Fixup: принимать input-тип схемы (`z.input`) или отдельный draft-тип, чтобы дефолт оставался в контракте.
5. **F-2.5.1-5: остальные AC Story 2.5 не закрыты.** Теги (фиксированные + свои ≤ 30, `label` с сервера, AD-22/AD-27) — 2.5.3+; запрет брони `UNLIMITED` — Story 5.4/5.5. Поэтому Story 2.5 остаётся `in-progress`.
6. **F-2.5.1-6: нет проверки паритета `QUANTITIES` и Prisma `GiftQuantity`.** Закрытый enum живёт в двух местах; межпакетный тест можно добавить отдельно.
7. **F-2.5.1-7: нет API-теста гонки `P2025`.** Гонка покрыта на уровне use-case; API-уровень не обязателен, но можно добавить.
8. **F-2.5.1-8: организация `quantity.test.ts`.** Файл смешивает POST коллекции и PATCH `[id]` и дублирует фикстуры соседних route-тестов; на поведение не влияет, перенос — по желанию.

Известный шум рабочего дерева (`apps/web/AGENTS.md`, `keyword-*`, `opencode-*`, промпты/логи, `fixup-queue.md`) не коммитился.
