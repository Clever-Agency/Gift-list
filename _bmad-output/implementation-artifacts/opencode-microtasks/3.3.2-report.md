## Поведение

1. Битый сегмент (`.`, `..`, `/`, `\`, `%`, `?`, `#`, пустой, >128) — `not_found` до сессии и БД; редиректа нет.
2. Валидная сессия и валидный сегмент — `redirect` ровно на `/wishlist/{token}`, собранный из проверенного сегмента. Pathname, query, `Referer`, cookie и `safeNextPath('/l/...')` не используются.
3. Нет сессии или cookie не признана — публичная страница; `readWishlist` с `viewer: null`, `viaListToken: true` отдаёт только `PUBLIC` и имя/ник владельца.
4. HTML: `h1` (`display-sm`) — имя, ниже `@ник`; карточки без чипа видимости и без счётчика скрытых. Пусто — ровно «Пока нет открытых желаний»; `not_found` — ровно «Список не найден», без отдельной фразы для Block.
5. CTA «Куплю сам» (формулировка `DESIGN.md` и эпика) — `<a>` только при `SINGLE` + `OPEN`, `href="/wishlist/{token}"`, `aria-label="Куплю сам: {название}"`. Брони, подтверждения и дружбы нет (AD-21, Epic 5). У `UNLIMITED` и не-`OPEN` ссылки нет.
6. Метаданные: «Вишлист {name} — {brand}» либо «Список не найден — {brand}» с общим описанием. Названий, цен, описаний, фото и числа скрытых нет; неизвестный, Block, мусор и редирект дают одинаковый not-found metadata.
7. Язык: `negotiateLocale(preferredFromAcceptLanguage(...))`, иначе `ru`. Proxy ставит внутренний заголовок только для `/l/*`; остальные маршруты (админка) остаются `ru`.
8. `public-wishlist-view.tsx` помечен `"use client"`, потому что корневой экспорт `@gift-list/ui` тянет хуки `Dialog`/`BottomSheet`/полей. Данные и метаданные остаются на сервере; SSR отдаёт разметку и CSS Tamagui.
