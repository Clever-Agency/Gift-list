## Что проверялось (поведение 3.4.1 + 3.4.2)

- `GET /api/v1/u/:nick` — тонкий AD-12 адаптер. Без сессии — `401 UNAUTHENTICATED`, тела желаний нет, база не читается.
- Ник нормализуется `normalizeNick` (AD-13), поиск только по `nickNormalized`; неизвестный, бывший после смены, невалидный ник, путь со слэшем и лишний сегмент дают один закрытый ответ `{ access: "not_found", gifts: [] }` без имени, email и желаний.
- Найденный пользователь читается только через `readWishlist({ viewer, target: { ownerId }, locale })` без `viaListToken`. Карточка `{ displayName, nick }` из `User.name` и `User.nick`; email, личные даты, `publicToken` чужому и число скрытых не отдаются.
- `hideFromSearch` прямой профиль не прячет. `Cache-Control: private, no-store`.
- Экран `apps/mobile/app/u/[nick].tsx`: аноним уходит на `/login` с безопасным `next=/u/{nick}`; вошедший читает только API и сам видимость не фильтрует. Карточка — имя и `@nick`; желания — `PublicGiftCard` без чипа видимости и счётчика; пусто — «Пока нет открытых желаний»; `not_found` и Block — «Пользователь не найден»; сеть/ошибка — текст и «Повторить»; смена ника не показывает прошлый профиль.
