## Intent

**Problem:** сервер уже отдаёт теги в карточке желания (`GiftCard.tags[]`, 2.5.5), форма умеет их выбирать (2.5.6), но `WishCard` в приложении их не показывает. Владелец и зрители не видят, насколько важно желание, хотя AC Story 2.5 требует, чтобы свой тег был виден всем, кто видит желание.

**Approach:** показать на карточке до трёх чипов из общих примитивов `packages/ui` и «+N» для остальных, как в `DESIGN.md` → WishCard. Подписи берутся только из серверного `label` (`catalogId`/`label`), без клиентских переводов фиксированных тегов. Пустые теги не занимают места; длинный свой текст переносится, ряд чипов переносится по ширине; теги входят в доступное имя карточки. Порядок — детерминированный: фиксированные по неизменному `slug` каталога, свои — по тексту, без учёта времени вставки. Действия карточки и `VisibilityPolicy` не меняются.

</frozen-after-approval>

## Implementation Notes

- `packages/ui/src/tag-chip.tsx`: у `TagChip` появляется `variant="card"` — статичный чип без `Pressable`, `role="checkbox"` и touch-target; `TagChipList` показывает не больше `max` (по умолчанию 3) подписей и сворачивает остальные в «+N». Видимый текст «+N» и доступное имя свёрнутого чипа приходят пропсами (`moreLabel`, `moreAccessibilityLabel`): в пакете нет строк интерфейса. Ряд — `flexWrap="wrap"`, чип ограничен шириной ряда, текст переносится.
- `packages/ui/src/wish-card.tsx`: проп `tags` рисуется между status pill и строкой брони; без пропа разметка прежняя.
- `apps/mobile/src/ui/gift-card.tsx`: подписи берутся из `gift.tags[].label`; при непустых тегах доступное имя кнопки карточки дополняется списком тегов (строка `app.gift.editWithTags`), чтобы теги читались скринридером, хотя визуальный ряд — часть кнопки. Свёрнутый чип получает `app.gift.tagsMoreLabel` со скрытыми подписями, поэтому теги за «+N» доступны и без `onPress`.
- `apps/web/src/domain/tag.ts`: `toGiftTags` сортирует фиксированные теги по `slug` каталога (кодовые единицы Unicode), свои — по тексту; фиксированные идут первыми. `slug` обязателен в `GiftTagRow.tag` и добавлен в `select` тегов в `gifts.ts` и `wishlist-read.ts`; на провод по-прежнему уходят только `catalogId` и `label`. Строковые фикстуры тестов обновлены, поэтому забытый `slug` ловится компилятором.
- Порядок не зависит от `createdAt`/`id` строк и времени вставки; ручной `sortOrder` не вводится (F-2.5.5-1/F-2.5.6-9 закрываются правилом показа). Равные ключи недостижимы из-за уникальностей `GiftTag`; индекс — только стабильный tie-break.
- Тесты: `packages/ui/src/tag-chip.test.tsx` (статичный чип, лимит 3 и «+N», `max=1`, пусто, длинный текст, доступное имя свёрнутого чипа, `flexWrap`), `wish-card.test.tsx` (ряд тегов, отсутствие лишних кнопок), `apps/mobile/src/ui/gift-card.test.tsx` (серверные подписи, несколько тегов, пусто, CLOSED/без `onPress`, длинный текст, доступное имя со скрытыми тегами, действие не изменилось), `apps/web/src/domain/tag.test.ts` (порядок по slug/тексту, кодовые единицы против `Intl.Collator`, независимость от порядка вставки), `apps/web/src/actions/gifts.test.ts` (порядок в ответе use-case).
- Проверки: `npm run typecheck`, `npm run lint`, `npm test` (mobile 524, web 474, contracts 164, ui 68, boundaries 5/5), `npm run build` — успешно. Визуальная проверка в браузере/на устройстве не выполнялась — отражено в отчёте микротаски.
- Story 2.5 остаётся `in-progress`: 2.5.8 — отдельный проход тестов/AC.
