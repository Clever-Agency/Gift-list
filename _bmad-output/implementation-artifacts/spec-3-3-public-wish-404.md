## Intent

При открытии `/l/:token/:giftId` Next.js проверяет, доступно ли конкретное активное желание текущему зрителю в списке по этому токену. Если желание скрыли от зрителя, перенесли в архив, удалили или оно из другого списка, возвращается общий HTTP 404 на исходном URL. Разрешённое желание открывается в приложении при действующей сессии и на публичной странице без неё. Видимость определяется AD-7, маршрут соответствует Story 3.3 и D-63.

</frozen-after-approval>

## Implementation Notes

- Запрос ограничен идентификаторами желания и списка, активными строками и видимостью зрителя. Применяется существующая `VisibilityPolicy`. Для прямой ссылки архив не читается.
- Редирект для вошедшего выполняется после проверки конкретного желания. Гость получает те же поля, что в карточке публичного списка.
- Веб-набор прошёл полностью, 1936 тестов с таймаутом 20 секунд. Проверка типов и ESLint изменённых файлов прошли.
- Проверка маршрута с авторизованным аккаунтом на развёрнутом staging остаётся за приёмкой.
