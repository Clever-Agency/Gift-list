## Intent

**Problem:** События дружбы и брони не доходят до получателей.

**Approach:** Добавить центр, счётчик, доставку Resend и независимые настройки двух каналов. Подключить существующие переходы, а новые источники подключать в 5.7, 6.6 и Epic 7.

## Boundaries & Constraints

**Always:** FR-26 определяет получателей и письма для существующих переходов. Канал подтверждения вручения из GIVEN согласуется в 5.7, где появится сам переход. AD-7 и FR-31 определяют видимость. Держателю разрешён снимок названия брони. Владелец видит держателя по переключателю, срок и отметку покупки получает только держатель. Настройки дат и срока желания независимы и по умолчанию включены. Доставка на языке получателя, лента на языке зрителя.

Продление владельцем создаёт только in-app `RESERVATION_KEPT_BY_OWNER` для держателя. Передаётся снимок названия и новый срок в ISO, дата отображается в поясе брони.

**Never:** Push, SMS, повторные напоминания о бронях, выключение писем брони и auth, побочные эффекты при открытии ссылки.

## I/O & Edge-Case Matrix

| Сценарий | Условие | Результат |
|---|---|---|
| Событие | Успешная транзакция | Одна строка на получателя. Повтор, проигранный CAS и откат пусты. При автоснятии получают оба. |
| Закрытие | До конца 10 минут | Лента, счётчик и отправщик ждут. Отмена удаляет запись. |
| Запрос | Фаза или экземпляр брони сменились | «Даритель уже ответил» без кнопок. Устаревшая мутация отклоняется. |
| Письмо | Нет сессии | HTTPS открывает центр, вход возвращает к записи получателя. |
| Каналы | Один канал выключен | Второй работает. Приватность проверяется при чтении и отправке. |

**Acceptance Criteria**

- Если два клиента повторяют событие, то ни строка, ни письмо не дублируются.
- Если получатель открывает центр на любой платформе, то видит только свои доступные события. Прочтение обновляет счётчик. Неизвестный kind имеет общий текст.
- Если письмо доставляется, то его первая строка берётся из общего каталога на текущем User.locale. Ссылка работает в браузере и установленном клиенте.

## Implementation Notes

- Веб-сборка добавила маршрут `/notifications` (3 014 байт gzip), каталог сообщений, счётчик и настройки. Зависимости и lock-файл совпадают с базовой версией.
- Замер CI после ревью: 715 613 байт gzip, прирост 227 821 байт при базе 487 792. Лимит поднят с 216 до 223 КиБ. Запас 531 байт.
- В Storybook проверены список, настройки и колокольчик в браузере на ширине 360 px. У списка нет горизонтальной прокрутки, высота кнопок 48 px, в панели доступности 0 нарушений и 20 пройденных правил.
- Standalone-сервер вернул SPA по ссылке из письма (HTTP 200), а запрос API без сеанса получил HTTP 401. Тест клиента подтвердил возврат к записи после входа и отсутствие мутаций при открытии письма.
- Доставка, отмена закрытия, проверки приватности и устаревшего действия проверены с тестовым транспортом и моками Prisma. Отдельный PostgreSQL и установленное приложение на Android или iOS в этом прогоне не использовались.

- После ревью исправлены гонка отмены с доставкой, продление после отметки «Купил», отдельная загрузка записи по ссылке, обработка устаревшего запроса и локализованный список полей в письме.
- Полный прогон после исправлений: 4 319 тестов, линт, production и Storybook. Standalone вернул 200 для ссылки из письма и 401 для API без сессии.
- Миграции 1–14 выполнены в изолированной PGlite. Проверены значения каналов по умолчанию, enum и уникальный индекс. Проверки блокировок между независимыми сессиями PostgreSQL и App Links на устройствах остаются открыты.
- Планировщик подключён в workflow для staging. Для production предусмотрено отдельное включение после продвижения и миграции.
