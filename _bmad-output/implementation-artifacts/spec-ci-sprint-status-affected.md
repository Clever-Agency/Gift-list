## Intent

Изменение только `sprint-status.yaml` запускает полный набор тестов, хотя это файл учёта работ. В выборочном режиме пропускать изменение этого файла и доказывать результат проверкой.

</frozen-after-approval>

## Implementation Notes

Без истории продукта. В `scripts/run-suite.mjs` добавить точное исключение для модификации `_bmad-output/implementation-artifacts/sprint-status.yaml`. При изменении только файла статусов запускаются проверки скриптов. При одновременной правке исходников тесты выбираются по этим исходникам. Другие YAML, удаление файла статусов и изменения общих пакетов по-прежнему попадают в полный набор. В `scripts/run-suite.test.mjs` закрепить эти случаи. Условия выбора режима в CI и полный прогон при push сохраняются.

На diff PR #134 (`392ca7b95f3a68066de5eb7da56928e98b8f85c7..9a5120b61d3e20788ccd4c50b014891725b262a4`) команда `npm run test:affected -- --base 392ca7b95f3a68066de5eb7da56928e98b8f85c7` запустила только проверки скриптов. Прошли 26 из 26. Для сравнения использовались временные Git-метаданные с HEAD PR, проверки выполнялись текущей версией скрипта.

Первый локальный запуск на Windows выявил различие CRLF и LF в сгенерированном манифесте иконок. Повторный запуск с манифестом, записанным генератором, прошёл.
