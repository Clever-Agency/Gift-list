## Intent

**Problem:** На регистрации и на экране нового пароля пароль короче 8 символов не сообщает требование «минимум 8 символов». И локальная проверка, и ответ сервера `VALIDATION` с полем `password` показываются общим текстом «Проверьте введённые данные.». В `EXPERIENCE.md` → «Ошибки форм» отдельной строки про длину пароля нет; показ — как у ошибки поля ника: текст каталога рядом с полем, без литерала в коде. Бренд только через `{brand}`.

**Approach:** В каталоге `ru` одна строка с этим требованием. Пока пароль короче 8 символов, под полем на регистрации и на новом пароле видна подсказка. Если проверка не прошла (клиент или сервер, поле `password`), та же строка становится ошибкой поля вместо общего `VALIDATION`. Экран входа не меняется. Тест покрывает подсказку и ошибку.

</frozen-after-approval>

## Implementation Notes

- Строка каталога `form.passwordRules`: «Минимум 8 символов». В экранах литерала нет, бренд по-прежнему только через `{brand}`.
- Пока пароль короче 8 символов, под полем на регистрации и на «Новый пароль» видна подсказка. После неуспешной проверки того же поля та же строка становится ошибкой: цвет `destructive`, рамка поля, `accessibilityRole="alert"`. Экран входа подсказку не показывает.
- Ответ сервера `VALIDATION` с `field: password` идёт в `passwordFieldIssue`. Короче 8 — требование. Уже 8 и больше — общий `errors.code.VALIDATION`: пароль длиннее 128 не должен называться «минимум 8».
- В `EXPERIENCE.md` → «Ошибки форм» отдельной строки про длину пароля нет. В коде оставлен `NOTE FOR UX`.
- Ключ `1-5-регистрация-и-один-вишлист` в `sprint-status.yaml` уже `done`. Синхронизация в `in-progress` и `review` его не откатывает.
- `expo start` переписал `apps/mobile/tsconfig.json` и удалил `expo-env.d.ts`. Оба файла возвращены и в изменение не входят.
- Проверено: `npm run typecheck`, `npm test`, `npm run lint`. Expo web: пустая регистрация показывает подсказку; пароль `1234567` и отправка дают текст и рамку `rgb(180, 35, 24)` (`#B42318`); то же на `/reset?token=live-token`. «Проверьте введённые данные.» при коротком пароле не появляется.
