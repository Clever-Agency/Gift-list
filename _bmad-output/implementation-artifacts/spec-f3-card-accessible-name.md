## Intent

**Problem:** нажимаемая карточка желания читается диктором как «Изменить «{title}». Теги: …»: в имени нет цены, статуса, строки брони и видимости, поэтому карточка не соответствует `DESIGN.md` → Доступность. Подтверждено в `fixup-queue.md` (Q-03, F-2.5.7-1).

**Approach:** собирать одно доступное имя нажимаемой карточки по фразе `DESIGN.md`: название, цена (если есть), статус, все теги в порядке показа (включая скрытые за «+N»), строка брони (если есть) и «видимость {значение}». Части разделяются запятой, пустые опускаются. Визуальный ряд чипов, порядок и поведение не меняются; нажатий на ряд или на отдельные чипы не добавляется. Проверка NVDA/VoiceOver/TalkBack остаётся ручным пунктом Q-06.

</frozen-after-approval>

## Implementation Notes

- Источник истины при расхождении с пересказом задачи — `DESIGN.md` → Доступность и `fixup-plan.md` → F3: в фразе перечислены **статус** и **видимость**, а не количество и не `updatedAt`; новых полей в имя не добавлялось.
- Объём F3 — только состав доступного имени. Остальные требования того же пункта `DESIGN.md` (основная зона-ссылка на деталь, `accessibilityActions`, декоративное фото) остаются открытыми и в этой правке не выдаются за выполненные.
- `apps/mobile/src/ui/gift-card.tsx`: имя собирается из `title`, `formatPrice(...)`, `tStatus(status)`, всех `gift.tags[].label`, строки брони и нового ключа `app.gift.visibilityInCardName` («видимость {value}»); пустые части отбрасываются, разделитель — «, ».
- `packages/contracts/src/i18n/ru/app.json`: добавлен ключ доступности `visibilityInCardName`; мёртвые строки действия `app.gift.edit` и `app.gift.editWithTags` удалены, чтобы прежняя модель имени не вернулась.
- `packages/ui/src/wish-card.tsx`: обновлён JSDoc `pressLabel`; заголовок больше не подставляется вместо полной фразы — без `pressLabel` имя кнопки собирается браузером из содержимого.
- Тесты `apps/mobile/src/ui/gift-card.test.tsx`: точная фраза со всеми частями и скрытыми тегами, обе фазы `ownerAction` вместо имени держателя, опускание пустых частей, обновление имени при смене данных, сохранение визуального порядка и отсутствие лишних кнопок. Селекторы карточки переведены с действия на содержимое.
- `apps/mobile/src/session/gift-flows.test.tsx` и `apps/mobile/src/session/my-wishlist-screen.test.tsx`: селекторы карточки больше не зависят от копии строки действия — берут основную кнопку `listitem` и проверяют, что имя начинается с названия.
- `packages/ui/src/wish-card.test.tsx`: примеры `pressLabel` переведены на фразу содержимого; добавлена проверка, что без `pressLabel` остаётся имя из содержимого, а не из одного названия.
- Проверено: focused mobile 100/100 (включая `gift-card.test.tsx` — 33), focused `packages/ui` 8/8; `npm run typecheck` — успешно; `npm run lint` — успешно; `npm test` — 1272 теста (mobile 557, web 480, contracts 164, ui 71) и 5 проверок границ; `npm run build` — успешно.
- Реальная БД, миграции, сиды и deploy не запускались; экранный диктор на устройстве не проверялся — это Q-06. Отчёт — `fixup-F3-report.md` отдельным коммитом.
