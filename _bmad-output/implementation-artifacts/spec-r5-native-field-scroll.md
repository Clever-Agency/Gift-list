## Intent

**Problem:** На Android и iOS при неудачной отправке формы `focusField` только вызывает `focus()` (для радиогрупп — `setAccessibilityFocus`). Если ошибочное поле выше или ниже видимой области, ScrollView может его не показать: зрячий пользователь не видит, где ошибка, хотя красная рамка и текст уже отрисованы.

**Approach:** `PageScroll` регистрирует свой нативный ScrollView в общем модуле прокрутки. `focusField` на native сначала измеряет поле относительно содержимого страницы и вызывает `scrollTo({ y, animated: false })`, затем перемещает фокус. Один механизм работает для всех форм: создание и правка желания, настройки, вход, регистрация, восстановление и сброс пароля. Web-ветка UI5 остаётся прежней: `focus()` + `scrollIntoView({ block: "center", behavior: "auto" })`. Без пульсации и анимаций. Красная рамка и текст ошибки остаются штатными `TextField`/`ChoiceList`.

</frozen-after-approval>

## Implementation Notes

- `packages/ui/src/field-scroll.types.ts` — общие типы: измеримый узел, ScrollView страницы (внутренний контейнер + `scrollTo`) и регистрация.
- `packages/ui/src/field-scroll.ts` — web-пустышка: регистрация ничего не делает, прокрутка сразу вызывает продолжение; web по-прежнему прокручивает сам input через `scrollIntoView`.
- `packages/ui/src/field-scroll.native.ts` — стек смонтированных страниц (верхняя активна, после её закрытия снова работает нижняя — Expo Router держит нижние экраны), `measureLayout` относительно внутреннего контейнера (`getInnerViewRef`) и `scrollTo({ animated: false })`; при ошибке измерения, отсутствии регистрации или молчащем измерении (запасной таймаут 250 мс) фокус всё равно выполняется.
- `packages/ui/src/page-scroll.tsx` — внутренний ref на ScrollView, `onLayout` запоминает высоту окна (`pageViewportHeight`), эффект регистрирует/снимает страницу.
- `packages/ui/src/focus.native.ts` — `focusField` прокручивает и только затем фокусирует; `restoreFocus`/`focusInLayer` не прокручивают. Общий комментарий web-версии обновлён.
- `apps/mobile/src/ui/gift-form.tsx` — поле своего тега (последнее в `FIELD_ORDER`) и при открытии редактора, и при ошибке отправки идёт через `focusField`, а не напрямую `focus()`, поэтому тоже прокручивается.
- Тесты: `field-scroll.native.test.ts` (моки measureLayout/scrollTo, центрирование, край страницы, отсутствие регистрации, ошибка измерения, снятие регистрации, стек страниц, таймаут), `focus.native.test.ts` (порядок «прокрутка → фокус», радиогруппа через `setAccessibilityFocus`, `restoreFocus` без прокрутки), `page-scroll-registration.test.tsx` (регистрация/снятие, высота окна).
- Web-регрессия — существующие тесты `gift-form.test.tsx` (UI5): фокус, `scrollIntoView`, красная рамка и текст ошибки; добавлена проверка прокрутки к полю своего тега.
- Не менялись: правила валидации и тексты, права, auth, маршруты, API, сервер, анимации.
