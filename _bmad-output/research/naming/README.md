# Нейминг Gift List

Здесь собраны кандидаты на название приложения и разбор каждого из них. Решение принимается по общим критериям и процессу BMAD «research a decision».

Приложение мультиязычное: пилот на русском, каталоги переводов с первой версии (`use-intl` / `next-intl`, D-46, AD-27). Имя одно на всех языках. Критерии это учитывают: произношение и плохие значения на русском и английском, написание кириллицей и латиницей, локализованный подзаголовок стора. Баллы в реестре посчитаны по прежней таблице и ждут переоценки — пометка в `ideas.md`, особенно про «Желанку».

## Структура

- `criteria.md`: общие критерии с весами и шаги процесса.
- `ideas.md`: реестр кандидатов со статусами.
- `<имя>.md`: полный разбор одного кандидата, например `what-to-give.md`.
- `opencode-prompt.md`: текст задания, чтобы прогнать проверку нового имени другим агентом.
