# Нейминг Gift List

Здесь собраны кандидаты на название приложения и разбор каждого из них. Решение принимается по общим критериям и процессу BMAD «research a decision».

## Структура

- `criteria.md`: общие критерии с весами и шаги процесса.
- `ideas.md`: реестр кандидатов со статусами.
- `<имя>.md`: полный разбор одного кандидата, например `what-to-give.md`.
